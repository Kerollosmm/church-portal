# دليل تثبيت ملف الـ APK (Android Sideload Guide Screenshots)

هذا المجلد مخصص للصور التوضيحية لخطوات تثبيت تطبيق الكنيسة (ملف APK) يدويًا على هواتف أندرويد.
تُعرض الصور داخل نافذة إرشادية (`showApkInstallGuide`) تفتح تلقائيًا عند بدء تنزيل التطبيق.

## أسماء الملفات المطلوبة

| الخطوة | الملف العربي | الملف الإنجليزي | محتوى اللقطة |
|---|---|---|---|
| ١ | `android-1-ar.webp` | `android-1-en.webp` | شريط تنزيل Chrome مع رسالة «قد يكون هذا الملف ضارًا» والتركيز على زر «تنزيل على أي حال» |
| ٢ | `android-2-ar.webp` | `android-2-en.webp` | إشعار «اكتمل التنزيل» أو قائمة التنزيلات وبها ملف الـ APK |
| ٣ | `android-3-ar.webp` | `android-3-en.webp` | رسالة إذن التثبيت من مصادر غير معروفة ← زر «الإعدادات» ← تفعيل مفتاح «السماح من هذا المصدر» |
| ٤ | `android-4-ar.webp` | `android-4-en.webp` | شاشة Google Play Protect مع زر «مزيد من التفاصيل» ← «التثبيت على أي حال» |
| ٥ | `android-5-ar.webp` | `android-5-en.webp` | أيقونة التطبيق المثبت على الشاشة الرئيسية + الرجوع لإلغاء إذن المصدر غير المعروف للأمان |

## المعايير الفنية للصور (Image Specifications)

1. **النسبة والأبعاد:**
   - نسبة العرض إلى الارتفاع: **9:16** (شاشة الهاتف الرأسية).
   - الأبعاد المقترحة: `540x960` بكسل أو `720x1280` بكسل.
2. **صيغة الملف والحجم:**
   - الصيغة: **WebP** فقط (`.webp`).
   - الحد الأقصى للحجم: **≤ 30 كيلوبايت** لكل صورة (تُحمّل عبر الشبكة عند فتح النافذة فقط ولا تزيد من حجم `main.dart.js`).
3. **الخصوصية والأمان (Privacy & Blurring):**
   - طمس أي بيانات شخصية (مثل أسماء شبكات الواي فاي، شريحة الاتصال، الإشعارات الشخصية، أو الحسابات).
   - التركيز والاقتصاص على مربع الحوار (Dialog) أو الرسالة ذات الصلة بالخطوة.
4. **الصور اختيارية:**
   - في حال عدم وجود أي صورة أو تأخر تحميلها، يعرض التطبيق إطارًا رماديًا مع أيقونة ختم الكنيسة وتسمية توضيحية بدون أن يتعطل أو يظهر خطأ للمستخدم.
