# التنويهات العاجلة وشريط الإعلان

## ماذا تقدم للزائر

- **التنويهات العاجلة**: في الرئيسية وصفحة المواعيد، أعلى تنويهين أولوية مع «عرض الكل (N)». لكل تنويه عنوان ونص
  وصورة اختيارية وزر «اعرف المزيد» يفتح صفحة داخلية (مثل صفحة التبرعات) أو قسمًا أو رابطًا خارجيًا.
- **شريط الإعلان**: سطر إعلان واحد في الرئيسية يكتبه المشرف مع رابط اختياري.
- إذا كان الرابط الداخلي يشير لقسم موقوف، لا يظهر زر «اعرف المزيد».

## التحكم من لوحة التحكم

- الشاشة **«التنويهات»** (`alerts`): «العنوان»، «النص» (حتى 1000 حرف)، **«مُفعّل»**، **«يبدأ / ينتهي»** (فارغ = بلا حد)، **«الأولوية (الأعلى يظهر أولًا)»** (0–1000)، **«رابط «اعرف المزيد» (صفحة، قسم أو
  رابط خارجي)»** مع زر **«اختيار صفحة…»** لاختيار صفحة مخصصة أو قسم، الصورة، و«ظاهر في الموقع».
- **شريط الإعلان**: «الأقسام والصفحة الرئيسية» ← بطاقة «شريط الإعلان» («إظهار شريط الإعلان»، «نص الإعلان»، «رابط
  الإعلان (اختياري)»).
- إيقاف التنويهات كلها: قسم «التنويهات العاجلة» (`alerts`). مكانهما في الرئيسية: «ترتيب الصفحة الرئيسية».

## كيف تعمل تقنيًا

- `visibleAlerts` في `lib/domain/rules.dart`: يظهر التنويه فقط إذا كان `active` والوقت الحالي بين `startsAt` و
  `endsAt`، مرتبًا بالأولوية تنازليًا ثم الأحدث بدءًا.
- الرابط: يبدأ بـ `/` واحدة = صفحة داخل التطبيق؛ `https://` أو `//` = خارجي.
- البيانات: مجموعة `alerts`، وحقول الشريط في `settings/features` (`bannerEnabled`، `bannerAr/En`، `bannerLink`).
- المساعد الذكي يعرف التنويهات السارية فقط.

## الحدود والمشاكل المعروفة

- التنويهات المرتبطة بمواسم (النهضات، أسبوع الآلام) تحتاج تحديثًا سنويًا.
