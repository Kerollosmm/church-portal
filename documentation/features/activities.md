# الأنشطة والكورالات

## ماذا تقدم للزائر

صفحة `/church-activities`: بطاقات مرتبة حسب التصنيف (خدمة، كورال، ألحان، شباب، إعداد خدام، إعلام، مسرح، كشافة،
شمامسة، دراسة كتاب، صيف، رياضة، معارض)، لكل بطاقة أيقونة التصنيف أو صورة، المواعيد، الأعمار، زر «افتح الصفحة»
(فيسبوك / يوتيوب)، واتصال وواتساب للموبايل، ورابط «التفاصيل».

## التحكم من لوحة التحكم

- الشاشة **«الأنشطة والكورالات»** (`activities`): «التصنيف»، العنوان، الوصف، «المواعيد»، «الأعمار»، الترتيب
  (سحب)، الظهور، «غير مؤكد»، ومجموعات التفاصيل والصور والتواصل (منها «رابط الصفحة (فيسبوك/يوتيوب…)»).
- إيقاف القسم: «الأقسام والصفحة الرئيسية» ← «الأنشطة والكورالات» (`activities`).
- العنوان والمقدمة: «عناوين الصفحات والمقدمات» ← «الأنشطة والكورالات».

## كيف تعمل تقنيًا

- الصفحة: `lib/ui/pages/activities_page.dart` (ترتيب التصنيفات `_categoryOrder`، ثم ترتيب المشرف).
- مجموعة `activities` (`category`، `titleAr/En`، `descAr/En`، `scheduleAr/En`، `ageRange`، `link`، `contactPhone`،
  `whatsapp`…).
- زر الرابط يحتاج `showSocials` للعنصر وقسم `socials` مفعّلًا؛ أزرار الهاتف تحتاج `showContacts`.

## الحدود والمشاكل المعروفة

- لا شيء خاص بهذه الميزة؛ المواعيد تُراجع مع مكتب الكنيسة.
