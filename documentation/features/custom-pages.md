# الصفحات المخصصة `/page/<slug>` (مثل صفحة التبرعات)

## ماذا تقدم للزائر

صفحات حرة يبنيها المشرف من «فقرات»، على `/page/<الرابط>` — مثلًا `/page/new-building-donations` لتبرعات المبنى
الجديد. الصفحة: عنوان وعنوان فرعي وصورة واجهة اختيارية، ثم الفقرات بالترتيب:

| نوع الفقرة | ما يظهر |
|---|---|
| عنوان | عنوان فرعي داخل الصفحة |
| فقرة | نص قابل للنسخ |
| صورة (رابط) | صورة من رابط https مع تعليق |
| زر | زر يفتح صفحة داخلية أو رابطًا خارجيًا |
| رابط نصي | رابط داخل النص |
| بيانات تبرع | بطاقة «بيانات التبرع»: الحساب البنكي، إنستاباي، محفظة الموبايل مع أزرار نسخ، وملاحظة «للعلم فقط: لا يتم أي دفع عبر الموقع.» |

الصفحة **لا تظهر في القائمة افتراضيًا**؛ يصل إليها الزائر من تنويه («اعرف المزيد») أو زر أو رابط.

## التحكم من لوحة التحكم

- **«الصفحات المخصصة»** (`pages`): العنوان، **«رابط الصفحة»** (حروف إنجليزية صغيرة وأرقام و-)، «العنوان الفرعي»،
  «صورة الواجهة (اختياري)»، **«محتوى الصفحة (حتى 20 فقرة)»** (لكل فقرة «نوع الفقرة» وتظهر حقولها فقط: النص، الرابط،
  «رقم الحساب البنكي (والبنك)»، «عنوان/رقم إنستاباي»، «رقم المحفظة»)، **«إظهار في القائمة»** (مُطفأ افتراضيًا)،
  الترتيب، الظهور.
- لربط الصفحة بتنويه: في «التنويهات» ← حقل الرابط ← **«اختيار صفحة…»**.
- إيقاف كل الصفحات المخصصة: قسم «الصفحات المخصصة (مثل صفحة التبرعات)» (`customPages`).

## كيف تعمل تقنيًا

- الصفحة: `lib/ui/pages/custom_page.dart` (`CustomPageView`، `PageBlockView`، `DonationInfoCard`). النموذج:
  `CustomPage` و `BlockTypes` في `lib/domain/custom_content.dart` (حتى 20 فقرة، نص الفقرة حتى 4000 حرف).
- مجموعة `pages`: `titleAr/En`، `slug`، `subtitleAr/En`، `image`، `blocks` (كل فقرة مخزنة كنص واحد مفصول بالحرف
  `\u001f` حتى تبقى قواعد الأمان في حدودها)، `showInNav`، `order`، `visible`.
- نفس منطق التحميل الآمن للأقسام المخصصة (`settleFirst`، PR #23؛ ومنذ PR #30 تظهر «غير متاحة» لرابط خطأ خلال ~13 ثانية كحد أقصى بدل 15–24). الصفحة محكومة بـ `customPages` + `visible`.
- المساعد الذكي يقرأ الصفحات المخصصة (حتى 20 صفحة، حتى 2500 حرف لكل صفحة) بما فيها بيانات التبرع.

## الحدود والمشاكل المعروفة

- تدخل خريطة الموقع المولَّدة عند النشر (PR #30، ADR-038) ما دامت ظاهرة ومفتاح قسمها مُفعّلًا؛ ما يُضاف بعد آخر نشر يظهر مع النشر التالي. انظر [seo.md](seo.md).
- صفحة التبرعات الحقيقية تنتظر بيانات الحساب من مكتب الكنيسة.
- الموقع لا يقبل أي دفع؛ البيانات للعرض فقط.
