# الصفحات المخصصة `/page/<slug>` (مثل صفحة التبرعات)

## ماذا تقدم للزائر

صفحات حرة يبنيها المشرف من «فقرات»، على `/page/<الرابط>` — مثلًا `/page/new-building-donations` لتبرعات المبنى
الجديد. الصفحة: عنوان وعنوان فرعي وصورة واجهة اختيارية، ثم الفقرات بالترتيب:

| نوع الفقرة | ما يظهر |
|---|---|
| عنوان | عنوان فرعي داخل الصفحة |
| فقرة | نص قابل للنسخ |
| صورة (رابط) | صورة من رابط https مع تعليق |
| زر | زر يفتح صفحة داخلية أو رابطًا خارجيًا |
| رابط نصي | رابط داخل النص |
| بيانات تبرع | بطاقة «بيانات التبرع»: الحساب البنكي، إنستاباي، محفظة الموبايل مع أزرار نسخ، وملاحظة «للعلم فقط: لا يتم أي دفع عبر الموقع.» |

مكان ظهور الصفحة يتحدد من **«مكانها فين»**:
- **لينك بس (من تنويه أو زر)** (`link`، الافتراضي): تصل إليها من تنويه («اعرف المزيد») أو زر أو رابط.
- **في القائمة** (`nav`): تظهر في القائمة الرئيسية.
- **جوه قسم كـ«اعرف المزيد»** (`section`): تظهر كبطاقة مع زر «اعرف المزيد» داخل القسم المختار (`/section/<slug>`).
- تفعيل **«مميزة (تظهر في الرئيسية)»** (`featured`): يضيف بطاقة للصفحة في الصفحة الرئيسية مع زر «اعرف المزيد».

## التحكم من لوحة التحكم

- **«الصفحات المخصصة»** (`pages`): عند الضغط على «إضافة» تظهر نافذة للاختيار بين **«صفحة فاضية»** أو **«صفحة تبرعات جاهزة»** (تفتح بعنوان وفقرة توضيحية وصندوق التبرع مع حقول حساب وإنستاباي ومحفظة فارغة ليملاها مكتب الكنيسة في ≤ 5 خطوات).
- يتولّد **رابط الصفحة** (`slug`) تلقائيًا من العنوان العربي (`slugFromTitle`) ولا يظهر إلا تحت قسم **«متقدم»** المطوي؛ وتعديل عنوان صفحة محفوظة لا يغيّر رابطها القديم.
- الحقول: العنوان، العنوان الفرعي، صورة الواجهة (اختياري)، «محتوى الصفحة (حتى 20 فقرة)»، «مكانها فين» (`placement` مع «القسم» `categoryId` عند اختيار الظهور داخل قسم)، «مميزة (تظهر في الرئيسية)» (`featured`)، الترتيب، الظهور.
- لربط الصفحة بتنويه: في «التنويهات» ← حقل الرابط ← **«اختيار صفحة…»**.
- إيقاف كل الصفحات المخصصة: قسم «الصفحات المخصصة (مثل صفحة التبرعات)» (`customPages`).

## كيف تعمل تقنيًا

- الصفحة: `lib/ui/pages/custom_page.dart` (`CustomPageView`، `PageBlockView`، `DonationInfoCard`)، وبطاقة الصفحة `CustomPageCard` في `lib/ui/pages/category_page.dart` (للقسم وللصفحة الرئيسية `HomePage`). النموذج: `CustomPage`, `PagePlacements` و `BlockTypes` في `lib/domain/custom_content.dart` (حتى 20 فقرة، نص الفقرة حتى 4000 حرف).
- مجموعة `pages`: `titleAr/En`، `slug`، `subtitleAr/En`، `image`، `blocks` (كل فقرة مخزنة كنص واحد مفصول بالحرف `\u001f` حتى تبقى قواعد الأمان في حدودها)، `placement`، `categoryId`، `showInNav` (متزامن مع `placement == 'nav'`)، `featured`، `order`، `visible`.
- نفس منطق التحميل الآمن للأقسام المخصصة (`settleFirst`، PR #23؛ ومنذ PR #30 تظهر «غير متاحة» لرابط خطأ خلال ~13 ثانية كحد أقصى بدل 15–24). الصفحة محكومة بـ `customPages` + `visible`.
- المساعد الذكي يقرأ الصفحات المخصصة (حتى 20 صفحة، حتى 2500 حرف لكل صفحة) بما فيها بيانات التبرع.

## الحدود والمشاكل المعروفة

- تدخل خريطة الموقع المولَّدة عند النشر (PR #30، ADR-038) ما دامت ظاهرة ومفتاح قسمها مُفعّلًا؛ ما يُضاف بعد آخر نشر يظهر مع النشر التالي. انظر [seo.md](seo.md).
- صفحة التبرعات الحقيقية تنتظر بيانات الحساب من مكتب الكنيسة.
- الموقع لا يقبل أي دفع؛ البيانات للعرض فقط.
