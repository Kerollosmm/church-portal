# تشغيل وإيقاف الأقسام

## ماذا تقدم

يستطيع المشرف إخفاء أي جزء من الموقع بمفتاح واحد دون حذف بياناته. القسم الموقوف **يختفي من كل مكان**: الصفحة
الرئيسية وأزرارها، دليل الخدمات، شريط التطبيق، قائمة الخدمات، القائمة الجانبية، روابط التذييل، الروابط المتبادلة،
**وسياق المساعد الذكي**. ومن يفتح رابطه مباشرة يرى «هذا القسم غير متاح حاليًا» مع زر العودة للرئيسية.

## المفاتيح الـ 19

`/admin` ← «الأقسام والصفحة الرئيسية» ← بطاقة **«تشغيل وإيقاف الأقسام»** (مع زر «تفعيل الكل») ثم «حفظ التغييرات»:

| التسمية في اللوحة | المفتاح | ما يتحكم فيه |
|---|---|---|
| القداسات والصلوات والمواسم | `schedule` | `/mass-schedule` وبطاقة القداس القادم |
| التربية الكنسية والاجتماعات | `meetings` | `/church-education` |
| العيادات | `clinics` | `/clinics` (**موقوف حاليًا**) |
| الخدمات العامة (الحضانة، التوظيف، القاعات، المكتبة، الأنبا أبرآم…) | `services` | `/public-services` |
| تاريخ الكنيسة والمذابح | `history` | جزء من `/about` |
| محطات تاريخية (قصتنا) | `milestones` | كتلة «قصتنا» وصفحاتها، وقسم «محطات الكنيسة» في `/about` (ومعه مفتاح فرعي «إظهارها أيضًا في «عن الكنيسة»»، ADR-052) |
| شفعاء الكنيسة | `saints` | جزء من `/about` + أقواس الواجهة |
| الآباء الكهنة | `priests` | جزء من `/about` |
| الآباء المتنيحون | `departedPriests` | جزء من `/about` |
| الأنشطة والكورالات | `activities` | `/church-activities` |
| التنويهات العاجلة | `alerts` | التنويهات |
| التليفونات والعنوان والخريطة | `contactInfo` | جزء من `/contact`، أرقام الرئيسية، الخريطة |
| روابط التواصل الاجتماعي | `socials` | جزء من `/contact` والتذييل وروابط العناصر |
| نموذج المراسلة | `contactForm` | جزء من `/contact` |
| اسأل الكنيسة (المساعد الذكي) | `assistant` | `/ask` (يحتاج أيضًا «تفعيل المساعد الذكي») |
| الصور (إظهار صور الآباء والشفعاء والأنشطة…) | `media` | كل الصور الاختيارية في الموقع |
| آية اليوم في الصفحة الرئيسية | `dailyVerse` | آية الواجهة |
| الأقسام المخصصة (وصفحاتها وروابطها في القائمة) | `customSections` | `/section/*` |
| الصفحات المخصصة (مثل صفحة التبرعات) | `customPages` | `/page/*` |

إذا لم يُحفظ شيء بعد: «لم تُحفظ إعدادات بعد: كل الأقسام مُفعّلة افتراضيًا.»

## كيف تعمل تقنيًا

- `lib/domain/features.dart`: `Sections` (القائمة والتسميات)، `FeatureSettings.enabled` (**المفتاح الغائب = مفعّل**)،
  `routeSections` و `sectionsForPath` (الصفحات متعددة الأقسام مثل `/about` و `/contact` تبقى ما دام قسم واحد مفعّلًا،
  وصفحات التفاصيل تتبع قسمها الأم).
- `FeatureGate` في `lib/ui/widgets/feature_gate.dart` يلف كل صفحة عامة، والصفحات تنتظر أول قراءة لـ
  `settings/features` (`featuresReadyProvider`) حتى لا يظهر محتوى موقوف للحظة.
- التخزين: `settings/features.sections` (خريطة `bool`)، والقواعد `validFeatures` تقبل المفاتيح الـ 19 فقط.
- بالإضافة لذلك كل عنصر له `visible` لإخفائه وحده.
- الاختبارات: `test/features_test.dart`، `test/feature_gate_test.dart`.

## الحدود والمشاكل المعروفة

- إضافة قسم جديد للكود يتطلب تعديل `Sections` و `routeSections` والقواعد والبذور معًا (قائمة الخطوات في
  [`08-dev-workflow.md`](../../docs/memory-bank/08-dev-workflow.md)).
