# ثيمات المناسبات والألوان

## ماذا تقدم للزائر

الموقع كله (الخلفية، الألواح، البطاقات، النصوص، الأزرار، التبويبات، العناوين، شريط القداس القادم، التذييل) يتلون
حسب **الثيم الساري**:

| الثيم | المفتاح | الشكل |
|---|---|---|
| الساعة الذهبية (الافتراضي) | `goldenHour` | رق وذهب وعنابي `#6E1C1C` |
| أسبوع الآلام (داكن) | `holyWeek` | خلفية سوداء، نص فاتح، لون فضي رمادي، كلمة الخط بالقرمزي، الصور رمادية خافتة |
| عيد القيامة (احتفالي) | `resurrection` | أحمر القيامة، ذهبي لامع، عاجي مضيء |
| عيد الميلاد | `nativity` | |
| عيد الغطاس | `epiphany` | |
| الأصوام | `fasting` | |
| أعياد السيدة العذراء | `marian` | |
| كحلي / أخضر / بني / بنفسجي | `navy`, `green`, `brown`, `purple` | تغيّر لون التمييز فقط فوق الساعة الذهبية |

يمكن أن يتبدل الثيم **تلقائيًا حسب التاريخ بتوقيت القاهرة**، بما في ذلك حساب عيد القيامة القبطي كل سنة.

## التحكم من لوحة التحكم

`/admin` ← **«الأقسام والصفحة الرئيسية»** ← بطاقة **«ثيم الموقع والمناسبات»**:

- **«الثيم المختار»**: أزرار بعينات الألوان، وسطر يوضح الثيم الساري اليوم ومصدره (يدوي / الجدول / عيد القيامة / الاحتياطي).
- مفتاح **«تبديل الثيم تلقائيًا حسب التاريخ»**:
  - مُطفأ: الثيم المختار يُطبَّق دائمًا (تجاوز يدوي).
  - مفعّل: يُطبَّق الجدول أولًا، ثم مواعيد عيد القيامة، وإلا الثيم المختار.
- مع التبديل التلقائي:
  - **«أسبوع الآلام والقيامة حسب حساب عيد القيامة القبطي»** (يعرض تواريخ هذه السنة المحسوبة).
  - **«مدة ثيم القيامة (أيام)»**: 1 أو 3 أو 7 أو 14 أو 40 أو 50 يومًا.
  - **«جدول المناسبات (تواريخ القاهرة، شاملة)»**: حتى 12 فترة؛ لكل فترة ثيم و«من» و«إلى» و«حذف الفترة»؛ زر «إضافة فترة».
- **«تعديل ألوان ثيم»** (قابل للطي): اختر الثيم، واكتب كل لون بصيغة `#RRGGBB`، مع معاينة حية وسطر حالة: «كل
  النصوص مقروءة (تباين ٤٫٥:١ على الأقل)» أو ما سيُصحَّح عند الحفظ. زر **«استرجاع ألوان الثيم الأصلية»**.
- ثم **«حفظ التغييرات»**.
- لوحة التحكم نفسها تبقى دائمًا بثيم الساعة الذهبية.

## كيف تعمل تقنيًا

- المنطق: `lib/domain/occasion_theme.dart` (`ThemePresets`، `ThemePalette`، `OccasionConfig.resolve`، حساب عيد
  القيامة القبطي)، والواجهة تقرأ الألوان عبر `context.pal`. المحرر: `lib/ui/admin/occasion_editor.dart`.
- البيانات في `settings/features`: `theme` (المفتاح المختار؛ القيمة القديمة `burgundy` وأي قيمة غير معروفة تُقرأ
  كساعة ذهبية)، `occasions` (`auto`، `easter`، `resurrectionDays`، `schedule` بفترات `r1…r12` كل منها نص
  `preset|YYYY-MM-DD|YYYY-MM-DD`)، و `themeColors` (الألوان المعدلة لكل ثيم).
- أي لون يجعل نصًا أقل من تباين 4.5:1 **يُصحَّح تلقائيًا** عند الحفظ (`OccasionConfig.withReadableCustom`).
- لكل ثيم فيديو واجهة اختياري (انظر [home-and-hero.md](home-and-hero.md)).
- القواعد: `validOccasions` و `validThemeColors` في `firestore.rules`. الاختبارات: `test/occasion_theme_test.dart`
  (تباين كل ثيم، حساب عيد القيامة 1900–2099، التبديل عند منتصف ليل القاهرة) و `test/occasion_admin_test.dart`.

## الحدود والمشاكل المعروفة

- فترات الميلاد والأصوام وأعياد العذراء لا تُحسب تلقائيًا: يجب إضافتها في الجدول كل سنة.
- مكتب الكنيسة لم يؤكد بعد شكل أسبوع الآلام والقيامة ولا مدة القيامة الافتراضية (7 أيام).
- لا يوجد ثيم داكن للوحة التحكم.
