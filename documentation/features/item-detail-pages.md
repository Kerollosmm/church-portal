# صفحات التفاصيل لكل عنصر

## ماذا تقدم للزائر

كل عنصر ظاهر في الأقسام السبعة التالية له **صفحة خاصة برابط قابل للمشاركة**:

| القسم | الرابط |
|---|---|
| الاجتماعات | `/church-education/<id>` |
| الأنشطة | `/church-activities/<id>` |
| العيادات | `/clinics/<id>` |
| الخدمات العامة | `/public-services/<id>` |
| الآباء الكهنة والمتنيحون | `/about/priests/<id>` |
| الشفعاء | `/about/saints/<id>` |
| المحطات التاريخية | `/about/milestones/<id>` |

في البطاقة رابط **«التفاصيل ›»** والضغط على البطاقة نفسها يفتح الصفحة. الصفحة تحتوي:

- «العودة إلى <القسم>»، العنوان، الشارات، صورة الغلاف ومعرض صور قابل للتكبير (إن وُجدت وسُمح بها).
- بطاقة **«المعلومات الأساسية»** (اليوم، الوقت، المكان، الأيام، المواعيد، الأعمار، تاريخ الرسامة، العيد، السنة…).
- أزرار سريعة: **«أضف إلى التقويم»** (اجتماع أو عيادة لها يوم ووقت — رابط Google Calendar أسبوعي بتوقيت القاهرة)،
  **«الاتجاهات (GPS)»** إلى الكنيسة (للأنشطة داخل الكنيسة)، و **«مشاركة الرابط»** (ينسخ الرابط ويظهر «تم نسخ الرابط»).
- النص الطويل، والحقول الإضافية (عنوان: قيمة) كبطاقات، وقسم التواصل والتسجيل، وروابط التواصل الاجتماعي.
- **«من نفس القسم»**: حتى 3 عناصر أخرى من نفس القسم.
- عنصر مخفي أو غير موجود أو صفحته مُطفأة: «هذه الصفحة غير متاحة حاليًا» مع رابط العودة (منذ PR #30 خلال 8 ثوانٍ كحد
  أقصى عند بطء الاتصال، لأن الاستعلام يبدأ مع فحص البذر لا بعده).

## التحكم من لوحة التحكم

في نموذج أي عنصر من الأقسام السبعة:

- مجموعة **«صفحة التفاصيل والحقول الإضافية»**: مفتاح **«إظهار صفحة التفاصيل»** (مفعّل افتراضيًا)، «التفاصيل (عربي /
  إنجليزي)» حتى 10000 حرف، و«حقول إضافية (عنوان: قيمة)».
- مجموعة **«الصور ومعرض الصور»**: «الصورة (اختياري)»، «طريقة عرض الصورة»، «عرض الصور في صفحة التفاصيل»، و«معرض
  الصور (حتى 8)».
- مجموعة **«التواصل والروابط»**: «عرض أرقام التواصل»، «عرض روابط التواصل الاجتماعي»، الأرقام والروابط، «نص زر
  الرابط»، و«طريقة التواصل / التسجيل».
- في قائمة العناصر تظهر شارة **«صفحة تفاصيل»** وأيقونة لفتح صفحة العنصر في الموقع.

## كيف تعمل تقنيًا

- الصفحة: `lib/ui/pages/item_detail_page.dart` (`ItemDetailPage`)، الأنواع في `lib/domain/item_detail.dart`
  (`DetailKind`، `detailPathFor`، `weeklyCalendarUrl`).
- لا قراءة إضافية من Firestore: العنصر يأتي من نفس قائمة القسم. صور المعرض المضمّنة (`media/{id}`) تُحمَّل في هذه
  الصفحة فقط.
- الحقول: `detailsEnabled` (الغياب = مفعّل، ADR-021)، `detailsAr/En`، `extraFields`، `gallery`، `showDetailImages`،
  `showContacts`، `showSocials`، `contactNoteAr/En`، `externalUrl`، `externalLabelAr/En`.
- الصفحة تُغلق مع قسمها (`sectionsForPath` في `lib/domain/features.dart`)؛ الصفحات المتاحة قابلة للفهرسة برابط
  canonical خاص، وغير المتاحة `noindex`.

## الحدود والمشاكل المعروفة

- روابط صفحات التفاصيل المتاحة تدخل خريطة الموقع المولَّدة عند كل نشر (PR #30، ADR-038)، بنفس شروط فتح الصفحة. انظر [seo.md](seo.md).
- عناصر الأقسام المخصصة ليس لها صفحات تفاصيل (البطاقة تعرض الوصف كاملًا).
- المشاركة تنسخ الرابط فقط (لا تستخدم قائمة المشاركة الأصلية في الهاتف).
