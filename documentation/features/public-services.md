# الخدمات العامة

## ماذا تقدم للزائر

صفحة `/public-services`: شبكة بالخدمات (الحضانة، التوظيف، القاعات، المكتبة، خدمة الأنبا أبرآم…) لكل منها أيقونة
حسب النوع أو صورة، الوصف، المواعيد، وزر اتصال، ورابط «التفاصيل». تظهر بطاقة اختصار للعيادات فقط إذا كان قسم
العيادات مفعّلًا (حاليًا موقوف).

## التحكم من لوحة التحكم

- الشاشة **«الخدمات العامة»** (`facilities`): «النوع» (خدمة، حضانة، توظيف، قاعات، أخرى)، الاسم، الوصف، «المواعيد»،
  الترتيب (سحب)، الظهور، «غير مؤكد»، ومجموعات التفاصيل والصور والتواصل («تليفون»…).
- إيقاف القسم: «الأقسام والصفحة الرئيسية» ← «الخدمات العامة (…)» (`services`).

## كيف تعمل تقنيًا

- الصفحة: `lib/ui/pages/public_services_page.dart`. مجموعة `facilities` (`type`، `nameAr/En`، `descAr/En`،
  `hoursAr/En`، `phone`…).

## الحدود والمشاكل المعروفة

- الحضانة والتوظيف والقاعات والمكتبة بلا مصدر مؤكد بعد؛ أُزيلت الأرقام والمواعيد غير الموثقة.
- حجز القاعات للمناسبات يتم من نموذج التواصل (نوع «حجز»)، انظر [contact-form-and-inbox.md](contact-form-and-inbox.md).
