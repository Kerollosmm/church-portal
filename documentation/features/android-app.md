# تطبيق Android والإشعارات المحلية (ADR-058)

## نظرة عامة

يُبنى تطبيق Android كحزمة مستقلة (APK) منفصلة حسب المعمارية (`arm64-v8a` للأجهزة الحديثة و `armeabi-v7a` للأجهزة الأقدم) لتقليل حجم التحميل والاستهلاك إلى أقل من 20 ميجابايت مع تصغير وضغط كامل عبر R8 ودعم مكتبات Java الحديثة عبر Desugaring (`desugar_jdk_libs:2.1.5`).

يعمل التطبيق بدون أي تكلفة على خطة Spark المجانية (+0 قراءات أو كتابات Firestore للزوار)، حيث يتم جدولة الإشعارات بالكامل محلياً على الجهاز.

| البند | الحالة والوصف |
|---|---|
| المعرّف (Package Name) | `com.asafrachurch.church_portal` |
| الاسم الظاهر | «كنيسة مكسيموس ودوماديوس» مع أيقونة الختم الكنسي الرسمي |
| معمارية الحزم | حزم منفصلة (Split APKs) لكل معمارية لتقليل الحجم |
| الإشعارات | إشعارات محلية مجدولة على الجهاز (آية اليوم، قطمارس، أعياد، تذكيرات «ذكّرني») |
| التحديث التلقائي | نظام تحديث داخل التطبيق (In-App Update) مع استئناف التحميل وفحص التجزئة SHA-256 |
| فحص طاقة البطارية | صفحة فحص وتشخيص أذونات وتوفير البطارية (`/notifications/battery`) بحسب كل مصنّع |
| قراءات القطمارس | قارئ يومي كامل للقراءات القبطية (`/readings/<date>`) يعمل بدون إنترنت من الذاكرة المحلية |
| حفظ اللغة | تخزين دائم لاختيار اللغة (عربي / إنجليزي) عبر `shared_preferences` |
| التنقل وزر الرجوع | دعم متكامل لزر الرجوع والرجوع للرئيسية مع تأكيد الخروج بنقرتين |
| لوحة الإدارة والمساعد | لوحة الإدارة مستبعدة تماماً من حزمة التطبيق؛ المساعد الذكي يفتح البوابة الإلكترونية بأمان |

## المزايا والوظائف

### 1. الإشعارات المحلية المجدولة (Local Notifications Planner)
- يتم التخطيط لجدول الإشعارات لمدة **9 أيام مقبلة** متجددة باستمرار.
- المواعيد الافتراضية بتوقيت القاهرة:
  - آية اليوم: 07:00 ص.
  - قراءات القطمارس اليومية: 06:30 ص.
  - الأعياد السيدية والمناسبات: 07:30 ص.
  - تذكيرات المستخدم («ذكّرني»): قبل موعد الخدمة أو القداس بالمهلة المحددة (مثلاً 15 دقيقة أو ساعة).
- مراعاة ساعات الهدوء (Quiet Hours): يتم ترحيل الإشعارات الصباحية لما بعد انتهاء فترة الهدوء.
- التكرار («كل مرة»): يتم تكرار التذكير أسبوعياً حتى 4 مرات مع تخطي الأيام التي تحل فيها مواسم خاصة (مثل أسبوع الآلام).
- الدقة: استخدام المنبهات الدقيقة (`USE_EXACT_ALARM`) مع التراجع التلقائي للمنبهات التقريبية (-10 دقائق) إذا رفض النظام إذن المنبه الدقيق.
- الأمان: سقف أقصى 80 منبهاً في النظام مع إعطاء الأولوية القصوى لتذكيرات المستخدم.
- التجديد بالخلفية: مهمة دورية عبر `WorkManager` تفحص الجدول كل 24 ساعة وتجدد الأيام عند بقاء أقل من 4 أيام.

### 2. قراءات القطمارس اليومية (`/readings/<date>`)
- شاشة مخصصة لعرض القراءات اليومية الكاملة:
  - نبوات باكر، إنجيل باكر، البولس، الكاثوليكون، الإبركسيس، السنكسار، مزمور وإنجيل القداس.
- شريط تنقل سلس بين الأيام والتقويم.
- نصوص الآيات كاملة باللغة العربية مع شواهد بالإنجليزية (`refs-only`).
- تخزين مؤقت محلي (`ReadingsStore`) يتيح قراءة اليوم والأيام السابقة دون الحاجة لاتصال بالإنترنت.

### 3. دليل تحسين البطارية والتشخيص المباشر (`/notifications/battery`)
- تشخيص فوري لحالة:
  - إذن الإشعارات (`POST_NOTIFICATIONS`).
  - إذن المنبهات الدقيقة (`SCHEDULE_EXACT_ALARM`).
  - استثناء توفير البطارية (Battery Optimization).
  - عمل مهمة التجديد في الخلفية (`WorkManager`).
- التعرف التلقائي على نوع الهاتف (Xiaomi / Redmi / POCO, Oppo / Realme, Vivo, Huawei / Honor, Samsung).
- أزرار مباشرة لفتح إعدادات البدء التلقائي (Autostart) وحماية التطبيق من الإغلاق في الخلفية مع توفير شرح مبسط لكل جهاز.

### 4. التحديث التلقائي داخل التطبيق (In-App Updates)
- يفحص التطبيق ملف النسخ `/app/android/version.json` عبر استضافة فايربيز عندما يكون رقم «إصدار APK» في لوحة التحكم أكبر من رقم التطبيق.
- في حال توفر إصدار جديد برقم بناء أعلى، يظهر شريط تنبيه أسفل الشاشة.
- إمكانية التحديث المباشر بضغطة زر مع عرض نسبة التقدم وسرعة التحميل واستئناف التحميل في حال انقطاع الشبكة عبر ميزة HTTP Range.
- التحقق الإلزامي من تطابق تجزئة SHA-256 قبل تثبيت الحزمة عبر `FileProvider`.
- في حال كان الإصدار الحالي أقل من `minSupportedBuild`، لا يمكن إخفاء شريط التحديث (يبقى التطبيق صالحًا للاستخدام).

## التحكم من لوحة الإدارة (`/admin`)

من قسم **«التطبيق والإشعارات»**:
- **روابط التحميل**: تعيين روابط APK الخاصة بالمعماريات 64-bit و 32-bit.
- **إصدار وبناء التطبيق**: تحديد `installApkVersion` و `installApkBuild`.
- **الحد الأدنى المدعوم**: تحديد `minSupportedBuild` لفرض التحديث على النسخ القديمة.
- **تخصيص الرسائل**: نصوص بنر التثبيت باللغتين العربية والإنجليزية.

## البناء والتطوير

يتم بناء التطبيق عبر أمر Flutter:
```bash
flutter build apk --release --split-per-abi --target-platform android-arm,android-arm64
```
يتم تشغيل مسار CI المؤتمت على جيت هب عبر `.github/workflows/android.yml` لفحص الأحجام ونشر النسخ تلقائياً عند إنشاء وسوم `apk-v*`.
