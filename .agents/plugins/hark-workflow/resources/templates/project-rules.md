# Standing rules (owner)

<!-- Short imperatives. Every agent reads these on every turn. Examples: -->
1. Everything visible to visitors is configurable from the admin dashboard; nothing user-facing is hard-coded.
2. Never invent content (names, times, phone numbers, photos). Unverified data stays marked as sample.
3. Never run the seed / migration with force, or edit live data, without the owner's explicit OK.
4. Images are optional everywhere; a card without an image looks exactly as before.
5. Error reporting is privacy-first: no form text, user ids, e-mails, IPs or query strings; session replay off.
6. Strings in both languages (Arabic RTL first, English LTR).
